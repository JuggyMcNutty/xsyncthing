# Syncthing Web GUI (vendored, unmodified)

The `gui/` tree of [syncthing/syncthing](https://github.com/syncthing/syncthing) at commit
`992ae894a44d8831bc92e002f68b4f20e5735117` (2026-11-23), MPL-2.0. The files are unmodified; Go files were left out.
xsyncthing serves them as Syncthing does (`lib/api/api_statics.go`): `<theme>/<path>` first, then `default/<path>`.

On the console, copy this folder beside the `.xex` as `gui/`, so the files are at `game:\gui\default\index.html`.
